IdentitasKu is an offline app to help you save your important data that you don't have time to remember.

**Features:**
- Save ID card, handphone number, address data in a centralized way
- Send those data to other applications such as chat app
- Copy the data wherever it's needed
- Data is saved locally & protected with password / fingerprint & encryption
- Material Design interface

**Tech Stack:**
- Kotlin
- Room Database
- Biometric Authentication
- Encryption
- Material Design Components
