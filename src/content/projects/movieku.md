An Indonesia Android Kejar Intermediate class final project. Data provided by The Movie Database (TMDb) API.

**Features:**
- Search movies
- View movie details, trailers, and reviews
- Browse popular and top-rated movies

**Tech Stack:**
- Java
- Android SDK
- The Movie Database (TMDb) API
- RecyclerView with custom adapters
