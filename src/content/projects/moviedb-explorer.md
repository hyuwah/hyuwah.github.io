MovieDB Explorer is an architectural sample of modern Android development using The Movie Database API.

**Features:**
- Browse popular movies
- View movie details
- Search functionality
- Offline caching
- Favorite movies list

**Architecture & Tech Stack:**
- MVVM Architecture
- Koin for Dependency Injection
- Jetpack Navigation
- Kotlin Coroutines
- Retrofit for API calls
- Room for local database
- Material Design Components
